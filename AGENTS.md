# Agent instructions for TraceLens

**This is a public AMD repository — never commit private, confidential, or
customer-related data.**

Before writing, editing, or reviewing any code in this repository, follow the
development conventions in
[`.agents/skills/tracelens-development/SKILL.md`](.agents/skills/tracelens-development/SKILL.md):
imports at the top of the file, reuse existing util modules instead of duplicating
helpers, consider cross-component impact and avoid unnecessary computation, and keep
comments/docstrings short and focused on the *why*.
