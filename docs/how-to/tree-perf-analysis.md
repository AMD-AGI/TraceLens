# Analyze GPU performance with TreePerf
```{meta}
:description: Learn how to use the TraceLens TreePerf software development kit to compute model- and operation-level GPU performance metrics from a PyTorch profiler trace.
:keywords: TraceLens, TreePerf, TreePerfAnalyzer, Trace2Tree, GPU performance, roofline, FLOPS, PyTorch profiler, ROCm, perf model
```

`TreePerf` is a Python software development kit (SDK) that works together with the `Trace2Tree` project. During profiling, PyTorch generates a trace JSON file, which `Trace2Tree` parses into a tree data structure that represents the hierarchical dependencies between CPU operations and GPU kernel executions. `TreePerf` builds on this tree structure to compute performance metrics at both the model and operation levels, so you can analyze, interpret, and optimize AI models with the detailed performance insights that are essential for architectural design and performance optimization.

## Before you begin

- TraceLens installed (see [Install TraceLens](../install/installation.md)).
- A PyTorch profiler trace JSON file for the model you want to analyze.
- A basic understanding of how `Trace2Tree` builds the tree (see [Trace2Tree](../conceptual/trace2tree.md)).

## Key ideas

- *Tree structure for GPU execution analysis*: the hierarchical tree structure, generated by `Trace2Tree`, enables straightforward computation of GPU execution times. By linking CPU operations to their corresponding GPU kernel launches, it allows seamless aggregation of kernel execution times and performance metrics at various levels of granularity.
- *Performance metrics from JSON parsing*: metrics such as floating-point operations per second (FLOPS) and FLOPS/Byte are derived by extracting operation parameters from the JSON event data structure. These parameters are parsed and fed into performance models, enabling precise computation of performance metrics.

## Key features

### GPU timeline breakdown

`TreePerf` provides a high-level view of GPU activity, which includes busy time, idle time, communication time, and so on. This timeline breakdown is computed by `GPUEventAnalyser`. For a standalone walkthrough of these metrics and how they're defined, see [Analyze a GPU timeline with GPUEventAnalyser](../how-to/gpu-event-analysis.md).

Example output:

|-------------------------------|--------------|------------|

### GPU compute time breakdown by CPU op

Analyze the performance breakdown by examining the lowest-level CPU operations (from the call stack perspective) and the time they "induce" on the GPU. Unlike traditional methods that directly look at CPU and GPU durations, this feature provides insight into how CPU operations translate into GPU kernel launches, offering a more stable and interpretable abstraction of performance.

## Add a new operation

Adding new operations is simple, and contributions are welcome:

- In [`perf_model.py`](https://github.com/AMD-AGI/TraceLens/blob/main/TraceLens/PerfModel/perf_model.py):
    - Parse operation shapes from the JSON trace.
    - Write the performance model (FLOPS, bytes) or reuse an existing one.
- In [`torch_op_mapping.py`](https://github.com/AMD-AGI/TraceLens/blob/main/TraceLens/PerfModel/torch_op_mapping.py): map the operation to the perf model here.

## Try it in a notebook

For more details and a walkthrough, check out the [`tree_perf_example.ipynb`](https://github.com/AMD-AGI/TraceLens/blob/main/examples/tree_perf_example.ipynb) notebook.

```{note}
Replace the profile path in `tree_perf_example.ipynb` with your profile file to get insights instantly.
```

Once you're familiar with the workflows, you can directly use or modify the [`generate_perf_report_pytorch.py`](https://github.com/AMD-AGI/TraceLens/blob/main/TraceLens/Reporting/generate_perf_report_pytorch.py) script to generate a report Excel sheet quickly.
